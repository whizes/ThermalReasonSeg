# ThermalReasonSeg

**Evidence-Guided Grounding for Reasoning Segmentation with Unregistered RGB-Thermal Inputs**

> **Code and benchmark release: coming soon.**

This repository is a temporary placeholder for the public release accompanying the associated paper. The release will provide the reproducible implementation and evaluation materials for ThermalReasonSeg, an RGB-thermal reasoning segmentation system that keeps RGB as the output coordinate anchor while using unregistered thermal observations as an additional visual modality.

The public release is planned to include:

- inference and evaluation code;
- training and configuration files;
- benchmark protocols and split manifests;
- selected qualitative examples and diagnostic visualizations;
- environment and reproducibility instructions.

The current placeholder intentionally contains no source code, model weights, restricted data, or benchmark images. Materials will be added after the review process and dataset-release checks are complete.
